# センマネ部 TIME SHOCK ⏱️

タイムショック風のクイズタイマー。飲み会用。

**▶ 公開ページ: https://kenhakoken-spec.github.io/time-shock/**

## 遊び方

1. **Start**(またはリングをタップ)で 60 秒カウントダウン開始
2. 緑のゲージが 1 秒ごとに 1 個ずつ消えていき、5 秒ごとに次の問題へ自動で切り替わります
3. 各問とも 3.5 秒経過で中央に答えが自動表示(進行中にリングをタップすると前倒しで表示)
4. 残り 10 秒でゲージが赤に変わり点滅 + ティック音が激しくなります
5. タイムアップで **答え一覧** が自動表示

## 問題の差し替え方法(2通り)

- **画面から**: 「問題編集」ボタン → 12 問の問題と答えを入力して保存(端末の localStorage に保存され、初期データより優先)
- **コードから**: `index.html` のスクリプト冒頭にある `DEFAULT_QUESTIONS` 配列を書き換え(`CONFIG` で制限時間・1問あたり秒数・答え表示タイミングも変更可)

## 機能

- 60 セグメントの緑ゲージリング + 中央に問題/答え表示(正解不正解の判定UIはなし)
- 効果音(ティック / 問題切替チャイム / 答え表示音 / 終了ブザー)は Web Audio 生成、🔊ボタンでON/OFF
- スマホ/PC両対応のレスポンシブ

## デプロイ

`main` または作業ブランチへの push で GitHub Actions が自動的に GitHub Pages へデプロイします(`.github/workflows/deploy.yml`)。
