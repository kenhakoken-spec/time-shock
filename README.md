# センマネ部 TIME SHOCK ⏱️

タイムショック風のクイズタイマー。飲み会用。

**▶ 公開ページ: https://kenhakoken-spec.github.io/time-shock/**

## 遊び方

1. 上部のタブで **SET 1〜10** から問題セットを選択
2. **Start**(またはリングをタップ)で 60 秒カウントダウン開始
3. 緑のゲージが 1 秒ごとに 1 個ずつ消えていき、10 秒ごとに次の問題へ自動で切り替わります(1セット6問)
4. 各問とも終了 1 秒前に中央に答えが自動表示(進行中にリングをタップすると前倒しで表示)
5. 残り 10 秒でゲージが赤に変わり点滅 + ティック音が激しくなります
6. タイムアップで **答え一覧** が自動表示

## 問題の差し替え方法(2通り)

- **画面から**: セットを選んで「問題編集」ボタン → そのセットの 6 問を入力して保存(端末の localStorage に保存され、初期データより優先)
- **コードから**: `index.html` のスクリプト冒頭にある `DEFAULT_SETS` 配列(10セット×6問)を書き換え(`CONFIG` で制限時間・1問あたり秒数・答え表示タイミングも変更可)

## 機能

- 60 セグメントの緑ゲージリング + 中央に問題/答え表示(正解不正解の判定UIはなし)
- 効果音(ティック / 問題切替チャイム / 答え表示音 / 終了ブザー)は Web Audio 生成、🔊ボタンでON/OFF
- スマホ/PC両対応のレスポンシブ

## デプロイ

`main` または作業ブランチへの push で GitHub Actions が自動的に GitHub Pages へデプロイします(`.github/workflows/deploy.yml`)。
