# センマネ部 TIME SHOCK ⏱️

タイムショック風のクイズタイマー。飲み会用。

**▶ 公開ページ: https://kenhakoken-spec.github.io/time-shock/**

## 遊び方

1. **問題編集** ボタンで 12 問の問題と答えを入力(端末のブラウザに自動保存)
2. **Start** で 60 秒カウントダウン開始 — 5 秒ごとに次の問題へ自動で切り替わります
3. 画面下の問題バーをタップすると答えを表示/非表示
4. タイムアップで **答え一覧** が自動表示(いつでも「答え一覧」ボタンでも見られます)

## 機能

- 本家風の時計盤UI(12パネル点灯・回転する針・スイープビーム)
- 残り10秒で赤点滅 + 加速ティック音
- 効果音(ティック / 問題切替チャイム / 終了ブザー)は Web Audio 生成、🔊ボタンでON/OFF
- スマホ/PC両対応のレスポンシブ

## デプロイ

`main` または作業ブランチへの push で GitHub Actions が自動的に GitHub Pages へデプロイします(`.github/workflows/deploy.yml`)。
